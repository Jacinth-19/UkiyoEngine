together: whatever else happens, the people whose work is inside keep their credit.

## Audio — CC BY 4.0, Oculus Audio Pack 1

`tools/afterglow_audio.py` builds the game's three sound files from recordings in the **Oculus Audio Pack 1**,
distributed with `github.com/facebookincubator/Meta-open-sound`. That pack is **CC BY 4.0**, so this is not
optional — here is the attribution as the pack itself states it, and it must ship with the game:

> "Oculus Audio Pack 01" by Oculus VR, LLC (https://developers.meta.com/vr/downloads/package/oculus-audio-pack-1/),
> licensed under CC BY 4.0. Files renamed to the UCS naming convention; OGG previews transcoded from the original
> WAVs.

Files used, as mixed, trimmed and layered by the tool (editing under CC BY stays CC BY):

| Source recording | Appears in |
|---|---|
| `WINDVege_LightWindTreesBirds` | `music/dusk_loop.wav` — the wind-and-birds bed |
| `MUSCChim_WindChimes` | `music/dusk_loop.wav` — the chimes |
| `UIMisc_BelltreeUp_OS_01` | `audio/bell.wav` — the shrine bell |
| `WHSH_WhooshMedium_OS_03` | `audio/spark.wav` — the lantern ignition |

## Audio — CC0, Meta Piano

The piano line in `music/dusk_loop.wav` uses six samples from **Meta Piano**
(`systems/instruments/meta-piano` in Meta-open-sound), licensed **CC0-1.0**. No credit is required; it is listed
so the soundtrack's provenance is complete.

## Made here, for the game

* `platform.glb`, `torii.glb`, `stone_lantern.glb`, `paper_lantern.glb` — generated by `tools/lantern_assets.cpp`,
  the same tool Lantern Run ships with; `lantern_assets --check` keeps them byte-exact in CI.
* The three finished wavs are mixdowns by `tools/afterglow_audio.py`, each pinned by sha256 in that tool.
* `AliciaSolid_vrm-0.51.vrm` — the hero, "Alicia Solid", a VRM sample character (already acknowledged in
  `README.md`'s third-party list alongside the animation library it rides).

If you replace any of these files in a downstream build, replace this file too — with something more accurate,
never less.
